# Tau Desktop downloads

Signed and notarized Tau Desktop builds for Apple Silicon Macs. Application source is maintained in a separate private repository.

Download an app from [Releases](https://github.com/Hire-Tau/tau-desktop-releases/releases). Quit the old app before replacing it. Your selected Tau data home is separate from the application.

The `updates/darwin-arm64.json` file is the desktop auto-update feed. Only signed, notarized releases are promoted there after upload verification.
